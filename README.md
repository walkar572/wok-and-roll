# t12-wok-and-roll
Teamwork 2026 - Team 12: Wok &amp; Roll

## Frontend

Run commands from the repository root:

```sh
npm install
npm run dev
npm run build
```

### Figma home page assets

The home page uses the supplied Figma light-mode design tokens, SVG icons, and food
images. The food images are generated concept artwork, not photographs of actual
restaurant dishes.
